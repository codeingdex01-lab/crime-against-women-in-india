# Crime Against Women in India – Data Analysis

## Project Overview
This project analyzes crime against women in India using data analysis and visualization techniques.

## Dataset
The dataset contains information about different crimes against women, including rape, kidnapping, dowry deaths, cruelty by husband or relatives, and other crimes.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Data cleaning
- Handling missing values
- Descriptive statistics
- District-wise analysis
- Year-wise analysis
- Crime trend analysis
- Data visualization

## Files
- `isha-checkpoint.ipynb` – Jupyter Notebook containing the analysis
- `DATASET-checkpoint.csv` – Dataset used for analysis
